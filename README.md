# EVE-NG FortiGate Site-to-Site Lab

## Project

Thiết kế và triển khai giải pháp hạ tầng mạng
bảo mật, tích hợp VPN site-to-site cho doanh nghiệp.

## Environment

- EVE-NG
- FortiGate
- Cisco Router
- Cisco Switch
- Windows Server
- Windows Client

## Main Functions

- VLAN
- Inter-VLAN Routing
- OSPF
- Internet NAT
- Firewall Policy
- IPsec Site-to-Site VPN
- DHCP
- DNS
- Web Server
- DoS Protection
